## 🧭 Decisions (and why)

- **One source of truth in .agent-handoff/session.json, every output is generated from it** — the formats cannot drift apart
- **Call git through subprocess instead of a library** — keeps the core dependency-free and behaves like the user's own git
- **An adapter is data (target name -> path) plus one generic block writer** — adding an agent is a one-line change for a first-time contributor
- **Marker-delimited HTML comment block, replaced in place instead of appended** — exports stay idempotent and user text outside the block is safe
- **Atomic writes (temp file, fsync, os.replace) with newline disabled** — CRLF files stay CRLF and no half-written file is possible
- **English-only CLI output and README, Indonesian and English import labels** — global audience, the importer still accepts both
